# Torta Studios Homebrew tap

Homebrew formulae for Torta Studios' tools.

```sh
brew install tortastudios/tap/proofmarks
```

Each tool's release workflow updates its formula here, so a new version is available as soon as it's released. To report a problem with a tool, open an issue in that tool's own repository.

| Formula | Repository |
|---|---|
| `proofmarks` | [tortastudios/proofmarks](https://github.com/tortastudios/proofmarks) |
